# Página de firma – Oficina de Telemática

Página estática que usa la Oficina de Telemática para que funcionarios y supervisores firmen los formatos de asignación de usuario (1DT-FR-0004, 0015 y 0016).

- **No contiene datos personales.** Los datos de cada solicitud viajan únicamente dentro del enlace que recibe cada persona por correo institucional y no se envían a este sitio.
- La firma se registra con un código de un solo uso, con dígito de control, que solo es válido para la persona a quien se le envió.
- Este repositorio no recibe comentarios ni contribuciones.
